Minecraft Intermedia

Adres serwera: minecraft.intermedia.lol
Sprawdzam…

Serwer zasypia po 15 minutach bez graczy. Jeśli śpi, obudź go hasłem z grupy. Gdy serwer laguje, wpiszcie w grze !boost: po zgodzie połowy graczy (albo od razu, jeśli pisze admin) serwer zapisze świat i przełączy się na mocniejszą maszynę. Po uśpieniu wraca do zwykłej.

Pobierz modpack

Fabric 1.21.1, ok. 20 modów, w tym Simple Voice Chat (rozmowy głosowe w grze, domyślnie klawisz V).

Pobierz intermedia.mrpack

Modrinth App

  1. Zainstaluj Modrinth App i zaloguj się kontem Microsoft.
  2. Kliknij + → Import from file i wskaż pobrany plik.
  3. Uruchom profil, wybierz Multiplayer → Add Server → minecraft.intermedia.lol.

Prism Launcher

  1. Zainstaluj Prism Launcher, dodaj konto Microsoft.
  2. Add Instance → Import → wskaż plik .mrpack.
  3. Przydziel ok. 6 GB RAM: Edit → Settings → Java.

Po aktualizacji paczki pobierz nowy plik i zaimportuj ponownie. Inna wersja modów niż na serwerze kończy się błędem przy łączeniu.
