minecraft.intermedia.lol
01

Obudź

Serwer gaśnie po kwadransie bez graczy, bo płacimy za każdą godzinę z budżetu studenckiego. Hasło jest na grupie. Start trwa 2–3 minuty.

02

Zainstaluj paczkę

Fabric 1.21.1, kilkanaście modów i Simple Voice Chat. Wersja u ciebie musi się zgadzać z serwerem. Kiedy admini coś dorzucą, paczka sama się aktualizuje, więc jeśli serwer cię nie wpuszcza, pobierz ją jeszcze raz.

Pobierz uap.mrpack

Modrinth App

  1. Zainstaluj Modrinth App, zaloguj się kontem Microsoft.
  2. + → Import from file → pobrany plik.
  3. W ustawieniach profilu daj grze ok. 6 GB pamięci.

Prism Launcher

  1. Zainstaluj Prism Launcher, dodaj konto Microsoft.
  2. Add Instance → Import → pobrany plik.
  3. Edit → Settings → Java: maksymalnie ok. 6 GB.
03

Graj

Multiplayer → Add Server → minecraft.intermedia.lol.

Mówisz z klawiszem V. Głośność i mikrofon ustawisz w menu Simple Voice Chat.

Jak laguje, napiszcie na czacie !boost. Gdy zgodzi się połowa osób na serwerze, świat się zapisze, a serwer przesiądzie się na mocniejszą maszynę. Przerwa trwa około trzech minut. Po uśpieniu wraca do zwykłej.

Mody i ustawienia: panel.minecraft.intermedia.lol, konto zakłada admin
